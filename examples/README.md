# Example subject lists

Import them from **Manage -> subject list -> Import list**. The `Class` column must match your class names exactly
(`Class 1`, `Semester 3`, ...), so set up your classes first.

* `papers_school_sample.csv` - three subjects each for Class 1-3.
* `papers_dibrugarh_university_fyugp_physics.csv` - the 48 Physics papers of the Dibrugarh University FYUGP syllabus (2024),
  for Semester 1-8 (core papers are compulsory, minor/elective/skill papers are optional).
